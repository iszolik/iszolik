🧪 Submenu AJAX URL Teszt

⚠️ Fontos: Ez a teszt szimulálja a különböző útvonal kontextusokat. A valódi környezetben az URL automatikusan a böngésző location-jéből származik.

Teszt Esetek

1. Gyökér Menü (Root)

Szimulált URL: https://www.fullroom.hu/index.php

2. Almenü (Submenu)

Szimulált URL: https://www.fullroom.hu/demo-tobbszallashely/index.php

3. Többszintű Almenü

Szimulált URL: https://www.fullroom.hu/menu1/menu2/submenu/index.php

4. Nincs index.php az útvonalban (Fallback)

Szimulált URL: https://www.fullroom.hu/booking/payment

5. Valódi Böngésző Location

Aktuális URL:

Implementáció

function buildAjaxUrl(pathname) { const origin = 'https://www.fullroom.hu'; // Keressük meg az index.php pozícióját const indexPhpPos = pathname.indexOf('index.php'); let ajaxPath; if (indexPhpPos !== -1) { // Megőrizzük az almenü struktúrát ajaxPath = pathname.substring(0, indexPhpPos) + 'index.php'; } else { // Fallback ajaxPath = '/index.php'; } return origin + ajaxPath; }
